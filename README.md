# Календарь

Мобильный календарь с планами на день. Задачи хранятся локально в браузере (`localStorage`).

## Возможности

- Месячный календарь в палитре бежевый / светло-зелёный
- Выбор дня сворачивает календарь до одной недели и показывает задачи
- Добавление текстовых задач (без времени и дедлайнов)
- Отметка выполнения (галочка + зачёркивание)
- Перетаскивание задач за ручку из трёх точек
- Точки под датами:
  - зелёная — будущее, есть невыполненные
  - жёлтая — сегодня, есть невыполненные
  - красная — прошлое, есть невыполненные
  - серая — прошлое, все выполнены

## Локальный запуск

Откройте `index.html` в браузере или поднимите простой сервер из корня проекта:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Затем откройте `http://localhost:8080`.

## GitHub Pages

Репозиторий: [Gregimuri/calendar](https://github.com/Gregimuri/calendar)

1. Запушьте содержимое в ветку `main`
2. GitHub → **Settings** → **Pages**
3. Source: **Deploy from a branch** → Branch `main` → Folder `/ (root)` → Save
4. Сайт будет доступен по адресу:  
   `https://gregimuri.github.io/calendar/`

Ссылки на CSS/JS относительные, поэтому базовый путь `/calendar/` поддерживается без дополнительной настройки.
